# Ruraap

Prototipo de billetera digital construido con React, Vite y React Router. Permite iniciar sesión, consultar el saldo, enviar dinero, retirar dinero y revisar el historial de movimientos.

## Ejecutar localmente

```bash
npm ci
npm run dev
```

La aplicación estará disponible en `http://localhost:5173`.

## Comandos

```bash
npm run lint
npm run build
```

Las operaciones son simuladas y se mantienen en el estado de la sesión del navegador. Todavía no hay autenticación ni persistencia en backend.
